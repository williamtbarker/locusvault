# Security policy

## Supported versions

The latest release on the default branch receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening a public issue.
Include the affected command, a minimal reproducer, and the observed impact when possible.

Do not submit confidential, identifying, clinical, or otherwise sensitive sequence data as part
of a report. LocusVault is intended for local research workflows and is not a security boundary
or a regulated clinical data system.
